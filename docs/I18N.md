# Languages

The command center ships with three interface languages:

| Code | Language | Selector |
|---|---|---|
| `pt` | Português (Brasil) | PT |
| `en` | English | EN |
| `es` | Español | ES |

Pick one in **06 / Interface → Language**. The choice is saved in
`~/.config/spectra-hud/config.json` and applies immediately to:

- the command center labels, status and buttons;
- the HUD cards, scan indicator and prompt dialogs;
- the tray menu;
- error and consent messages.

## Model response language

The base system prompt (`prompt_system.md`) is written in Brazilian Portuguese,
but the app appends a **RESPONSE LANGUAGE** directive to every scan and follow-up.
If you select English or Spanish, the model answers in that language. The
directive is intentionally last so it overrides the prompt's earlier language
rule.

## Adding a language

1. Add a dictionary under `TRANSLATIONS` in `i18n.py` (the key set must match
   `pt` exactly).
2. Add the code and label to `LANGUAGES` and a short selector label to `SHORT`.
3. Add the code to the language pill row in `settings.py`.
4. Add the model-language name to `LANGUAGE_NAMES` in `ai_client.py`.
5. Run `pytest -q`; `test_catalogs_have_the_same_keys` catches missing keys.

The fallback is always Brazilian Portuguese, so a missing translation key never
leaves the UI blank.

ALERTA

Bring your own key.

Any OpenAI-compatible vision endpoint. The key stays in .env. No Spectra account.

# .env
SPECTRA_API_KEY=sk-•••
SPECTRA_MODEL=your-vision-model

Memory that expires.

The last ten events feed the next scan, then expire after an hour of silence.

TTL 60:00

Multi-monitor, actually.

Captures the display under the mouse, not always the primary. Cards are clamped to that screen.

It tells you when it fails.

No silent empty cards. Errors surface in the HUD with the reason and a timeout.

ERROR / HTTP 401 · key not set

Geometry, schema and parsing are covered. The overlay is tested by hand on X11.

Scan or closeCaptures the active monitor, or clears the HUD.
Ctrl+Shift+Space
Command barAsk anything about the current screen.
Alt+123
Open a cardJumps straight to the question box.
Esc
DismissCloses the prompt or cancels.
Drag
Move a cardAnywhere on the current monitor.
HEADS-UP

Ctrl+Space collides with IDE autocomplete.

VS Code and JetBrains own that shortcut. If you code with Spectra open, change it:

SPECTRA_HOTKEY=<ctrl>+<alt>+<space>
04

It sees your screen.
That is the point.

Every scan sends a JPEG of the active monitor to the endpoint you configure. There is no Spectra server, no account and no telemetry.

05

Clone. Add a key. Run.

No package yet. The installer creates a virtualenv, copies the config and registers a desktop entry.

  • PLATFORM Linux with X11
  • PYTHON 3.10 or newer, with Tkinter
  • SYSTEM xdotool
  • KEY any OpenAI-compatible vision endpoint

Wayland is not supported in v0.1. Capture and global hotkeys need X11.

# 2. install
cd spectra-hud && ./install.sh
# 3. add your key
nano .env
# 4. run
./run.sh
